# Project rules

## Attribution

This project's authorship belongs to the repository owner alone.

- Commit messages carry only the repository's own author identity: no `Co-Authored-By` trailers for tools, assistants or AI services, no "generated with …" footer lines, no bot emoji footers.
- `README.md`, docs, code comments, PR descriptions and issues describe the project and its dependencies, never the tooling used to type it. No "made with / built by / generated by <assistant>" lines.
- A local `commit-msg` hook strips such lines if they slip in; do not remove or weaken it.
- Third-party libraries, actions and services are still credited normally where they are part of the code, as `README.md` already does.

Everything else in this repository follows the normal conventions described in `README.md`.
