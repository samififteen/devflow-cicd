DevFlow is a small Flask application wrapped in a real CI/CD pipeline: every push runs code quality checks and tests, builds a Docker image, publishes it to GitHub Container Registry and deploys it to a hosting platform — then verifies that the deployed service answers /health.

The badge above calls GET /health from your browser, so it always reflects the instance you are looking at.

Backend

Python 3.12 + Flask application factory, served by Gunicorn in production.

Automation

GitHub Actions runs Ruff, pytest and a Docker build on every pull request.

Delivery

Images are published to GHCR tagged with the commit SHA; deploys run only from main.

Verification

After a deploy the workflow polls /health and fails if the service is down.

Pipeline stages

These stages are configured in .github/workflows/. They describe what the pipeline does — actual run results live in the repository's Actions tab.
