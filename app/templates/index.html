A small Flask app that exists to be tested, containerised and deployed.

Every push runs Ruff and the pytest suite, then builds the Docker image. If main is green, the image is published to GitHub Container Registry, the host is told to deploy it, and the workflow polls the live /health endpoint until it answers.

Nothing on this page is a mock. Where this instance genuinely has no information — the commit SHA of a deployment that has not happened, for example — it reports that instead of inventing a value.

API

Three JSON endpoints, plus the HTML page you are reading.

GET /health
Liveness probe. Called by the Docker HEALTHCHECK, the CI smoke test, the host's health check and the post-deploy verification step.
GET /api/info
Version, environment, interpreter details and optional build identifiers. No secrets.
GET /api/pipeline
The six stages above, explicitly marked as configuration with no execution results.
$ curl -s http://127.0.0.1:5000/health
{"service":"devflow","status":"healthy","version":"1.0.0"}

Reproduce it

The same checks the workflow runs, on your machine.

$ ruff check . && ruff format --check .
$ pytest -q
$ docker build -t devflow:local .
$ docker run --rm -p 8000:8000 -e APP_ENV=production devflow:local
